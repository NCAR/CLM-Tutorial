CTSM Workflow#

CLM has been designed to be easy to use. Once you have downloaded the CLM code, a CLM case can be run with a set of 4 commands.

Note: In CLM jargon, a case refers to a specific instance of a model simulation.

  1. Create a new case using create_newcase

  2. Set up the case by invoking case.setup

  3. Build the executable using case.build

  4. Run your case using case.submit

The following sections will go into more detail about these 4 commands and also provide information about how to check your job status or create a clone of a previous case.

More information#

While there is not yet fully published documentation for CLM6/CESM3 workflow, it is very similar to the CLM5/CESM2 workflow. And we have documentation for the latest model version, with the caveat that it isn’t fully accurate or completed yet. Detailed information on the CLM6/CESM3 Workflow is in the following links.
