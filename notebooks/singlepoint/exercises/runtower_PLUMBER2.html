Run_tower: PLUMBER2#

Exercise: use the run_tower script to run a single point case at a PLUMBER site

Create a case called BR-Sa3.test0 using the run_tower script in tools/site_and_regional.

Note: You will need to activate the ctsm_pylib conda environment to use the run_tower script. After creating your case you can check the status of the run after submitting.

Please ensure that you have completed all steps in the Download CTSM Tutorial before starting this exercise!

Assumptions#

Here are some assumptions we’ve built into PLUMBER2 simulations that use the run_tower script:

  • Surface datasets: may have one or several multiple PFTs, depending on the site. They have not been otherwise modified.

  • Data Atmosphere (DATM): Are of various lengths and set individually for each site.

  • Compset: You’ll be running a BGC case, but if you run an SP case we have LAI streams for each site.

  • Parameter files: Are default for the physics version of CLM being used. They have not been calibrated to site-level observations.

  • Initial conditions: Are not provided, you’ll need to do your own spinup for PLUMBER2 cases, therefore the default run-type is for accelerated decomposition (AD) mode.

Get started#

Let’s use run_tower at a PLUMBER2 site.

Click here for hints

Is my workspace set up?

Did you already create a cases directory where you will put all new cases? Note that you will need to use a run_tower option to put your created cases there!

cd /glade/u/home/$USER
mkdir -p cases

How do you use run_tower?

activate ctsm_pylib:

conda activate ctsm_pylib

move into the tools/site_and_regional directory and ask for help!

cd /glade/u/home/$USER/code/my_clm_code/tools/site_and_regional
./run_tower --help

Look at all the options you have for running tower sites!

HINT: use the --experiment flag to add test0 to your case name.

Use run_tower to create, setup, build and submit a case

A single run_tower command handles the whole CTSM workflow (create, setup, build, and submit). For a PLUMBER2 site it does four things, in order:

  1. Builds a base case This compiles CTSM once and takes a few minutes.

  2. Clones the base case into the case you’ll actually run.

  3. Configures the case to use the correct surface dataset and DATM data. We have copies of these files for PLUMBER2 sites.

  4. Submits the case to the queue.

How do I check my job status?

You can check job status using the command:

qstat -u $USER
Click here for the solution

Create a new case BR-Sa3.test0 with the command:

cd /glade/u/home/$USER/code/my_clm_code/tools/site_and_regional

./run_tower --plumber-sites BR-Sa3 \
--output-root /glade/u/home/$USER/cases \
--experiment test0 \
--xmlchange PROJECT=UCGD0011

Move to your case directory: BR-Sa3.test0.ad:

cd /glade/u/home/$USER/cases/BR-Sa3.test0.ad

Check the status:

qstat -u $USER

When the run is completed, look into the archive directory for: BR-Sa3.test0.ad.

Check that your archive directory contains outputs:

cd ~/cases/archive/BR-Sa3.test0.ad
ls
